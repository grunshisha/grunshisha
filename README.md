# Caravan — Silk Road Shisha Café Website

A responsive single-page website concept mixing Middle Eastern hospitality with Central Asian and Silk Road-inspired visual details. Built with plain HTML, CSS, and JavaScript; no build tools required.

## Preview

Open `index.html` in a browser. Google Fonts and the Unsplash photography are loaded remotely.

## Before publishing

- Replace the sample brand name **Caravan** with the café's name.
- Update the address, city, opening hours, phone/email, and menu to match the real business.
- Replace the Unsplash images with approved cafe photography and confirm image usage rights.
- Connect the reservation form to a real booking service or backend. It currently only shows a preview notice and does not transmit form data.
- Review menu descriptions, allergens, age restrictions, and local rules for shisha service.

The site is a static prototype and contains placeholder business details by design.
